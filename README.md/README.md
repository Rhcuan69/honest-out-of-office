`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — a brutally honest but still polite out-of-office auto-reply that admits the return date is more rumour than plan. The output is deterministic: every run produces byte-identical output.

> I'm away, and honestly my return date is more rumour than plan, so your email will wait for fresh eyes and real attention when I'm back - thank you for trusting me with the wait.

## Run it

```sh
python3 main.py
```
